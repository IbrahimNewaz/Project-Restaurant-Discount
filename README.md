# Restaurant Discount System 🍽️

## Description
This JavaScript program calculates discounts based on three conditions:
- 🧒 **Children under 12 eat for free**
- 👴 **Customers over 60 receive a 60% discount**
- 🧑 **If you are dining alone, you get a 15% discount**

The program efficiently determines the appropriate discount based on user input and calculates the final bill.

## Features
- ✅ Applies dynamic discount conditions
- ✅ Handles user input for age and party size
- ✅ Ensures accurate pricing calculations
- ✅ Simple and interactive execution via the terminal
**Follow the prompts** to enter details and get the final bill.

## Technologies Used
- **JavaScript** – Core programming language
- **Node.js** – Runtime environment
- **Prompt-sync** – For interactive user input
